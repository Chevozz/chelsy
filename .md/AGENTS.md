# Project: For Chelsy ♡

## Core Design Direction

PRIMARY:
**ROMANTIC EDITORIAL + DIGITAL LOVE LETTER**

SECONDARY:
- film photography
- scrapbook
- elegant editorial layouts
- subtle paper texture
- handwritten accents
- soft neumorphism for controls
- cinematic micro-interactions

Neumorphism is NOT the main visual language.

Use it selectively for buttons, music player, small interactive controls, counters, and pressed states.

Do not make every section a neumorphic card.

## Emotional Direction

curiosity → warmth → nostalgia → playfulness → intimacy → heartfelt ending

The final letter should be the emotional climax.

## Layout

Do not use repetitive card grids for the entire website.

Create rhythm with:
- large whitespace
- full-width photography
- asymmetric editorial layouts
- centered text moments
- narrow reading columns
- occasional cards
- timeline structures
- large typography
- visual pauses

## Typography

Display: Playfair Display, Cormorant Garamond, or DM Serif Display.
Body: Inter, Manrope, or DM Sans.
Handwriting fonts only for tiny accents/signatures.

## Color

Favor:
- ivory
- warm white
- beige
- soft taupe
- muted rose

Avoid neon, excessive pink, excessive purple, and saturated gradients.

## Photography

Personal photos are a primary storytelling tool. Preserve their natural character and give them visual importance.

If unavailable, use intentional placeholders. Never invent personal photos.

## Animation

Use subtle cinematic motion:
- fade
- reveal
- gentle translation
- image mask
- subtle scale
- soft hover
- letter opening
- timeline reveal

Avoid excessive bouncing, particle overload, dramatic zoom, and heavy parallax.

## Music

Never autoplay sound without interaction. Provide clear controls and graceful missing-audio handling.

## Accessibility

Use semantic elements, visible focus, keyboard navigation, sufficient contrast, alt text, reduced motion, and comfortable touch targets.

## Responsive

Test:
320px, 375px, 414px, 768px, 1024px, 1280px, 1440px+.

Mobile must be deliberately designed.

## Definition of Done

The result should not feel like a collection of components. It should feel like one continuous story.

Target feeling:
"This was made specifically for Chelsy."
