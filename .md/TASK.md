# TASK.md

## Main Objective

Build the complete romantic editorial website for Chelsy.

Primary:
ROMANTIC EDITORIAL + DIGITAL LOVE LETTER

Secondary:
SUBTLE NEUMORPHISM

## Phase 1 — Inspect

1. Inspect repository.
2. Identify framework and package manager.
3. Inspect existing components.
4. Inspect available images/audio.
5. Inspect current styling.
6. Reuse infrastructure where sensible.
7. Do not replace the stack unnecessarily.

## Phase 2 — Foundation

Create:
- color tokens
- typography
- spacing
- editorial grid
- responsive breakpoints
- image treatment
- subtle texture if appropriate
- neumorphic control styles
- animation tokens

## Phase 3 — Narrative

Implement:
1. Hero
2. Introduction
3. First photo moment
4. Timeline / Our Little Story
5. Little Things I Love About You
6. Photo Gallery
7. Music
8. Love Letter
9. Final Message
10. Footer

## Phase 4 — Interaction

Implement meaningful:
- smooth scrolling
- section reveal
- photo reveal
- timeline reveal
- tactile button states
- music play/pause
- letter opening

Do not add interactions merely for decoration.

## Phase 5 — Responsive

Test:
320px, 375px, 414px, 768px, 1024px, 1280px, 1440px+.

## Phase 6 — Content Integrity

Use CONTENT.md.

Never invent dates, places, memories, conversations, relationship events, or personal facts.

## Phase 7 — Polish

Focus on:
- typography
- whitespace
- image composition
- section rhythm
- visual hierarchy
- transitions
- shadows
- button states
- mobile spacing

Remove unnecessary elements.

## Phase 8 — Validation

Run development server, build, lint, and tests when available.

Fix console errors, broken imports, broken images, broken links, overflow, and accessibility issues.

## Definition of Done

The final result should feel like one continuous story, not a collection of components.

Target:
"Someone made a beautiful little corner of the internet just for Chelsy."
